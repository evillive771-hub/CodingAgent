# ADR-0012：有界模型恢复与工具失败熔断

## 状态

Accepted

## 背景

模型适配器已有 HTTP 级有限重试，但 Agent Loop 遇到适配器最终错误后立即失败；协议格式错误也没有
受控的纠正机会。另一方面，宿主自动重放工具可能重复写文件或制造外部副作用，不能使用与模型请求
相同的重试方式。

## 决策

- 模型错误分类为 transient、rate limit、protocol、authentication、request 和 unknown；MiMo
  适配器保留短暂传输重试，并向 Agent 暴露安全、带 `retryable` 元数据的最终错误；
- 每个 Agent Run 创建独立 `RecoverySession`。可重试模型调用使用有上限的指数退避，尊重被限制在
  300 秒内的 `Retry-After`，并记录 scheduled、recovered 或 stopped 事件；
- 协议错误重试只向该次请求增加临时纠正提示，不污染持久化 transcript；认证和请求错误立即停止；
- 相同模型失败达到阈值时提前熔断，即使总重试预算仍有剩余；
- 宿主永不自动重放工具。模型可以根据成对工具结果重新决策，但完全相同的工具名、参数和失败输出
  连续达到阈值后，Run 以可审计原因失败；成功工具结果重置连续失败计数；
- 用户 Steering 取消的工具不计入失败熔断。

## 结果

临时模型故障和偶发协议错误可以自恢复，同时认证配置错误和重复失败更快暴露。写工具及未来外部
工具不会因恢复模块被宿主隐式重复执行。
