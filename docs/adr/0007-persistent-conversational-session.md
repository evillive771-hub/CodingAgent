# ADR 0007：持久化对话会话

## 状态

已接受。

## 背景

一次性任务 JSON 和 CLI 参数适合无人值守交付，但不适合人机协作。用户需要像 Claude Code 一样
连续提出问题、追问修改、补充需求，并在需求不明确时回答 Agent 的澄清问题。

## 决策

在现有 `AgentLoop` 外增加 `ChatSession`，不复制或放宽工具执行内核。每条用户消息派生一个受
工作区 profile 约束的本地任务合同；本轮完成后持久化用户消息、Agent 最终答复、结构化结果和
运行统计。后续轮次注入最近的用户/Agent 对话，不重复注入旧工具输出。

增加 `ask_user` 工具和 `waiting_for_user` 状态。该工具暂停当前 Agent Loop，把具体问题交还给
交互层；下一条用户消息以新一轮继续。只读结果不要求运行代码验证，任何写操作仍必须满足原有
Stop Gate。

会话 transcript 使用只追加 JSONL 和受限 session ID，默认位于工作区受保护的
`.aicoding-agent/`。它不进入模型写权限，也从 Git 变更快照中排除。

## 结果

用户只需启动一次 `chat` 即可持续自然语言协作，同时保留已有权限、证据和发布边界。当前版本
保留的是用户消息与最终摘要，不是完整跨轮工具历史；更长会话的模型摘要压缩和分支会话属于后续
增强。
