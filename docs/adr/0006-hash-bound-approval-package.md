# ADR 0006：哈希绑定的结构化审批包

## 状态

已接受。

## 背景

只对代码差异计算审批哈希不足以证明审批人看到的是哪份任务合同、测试部署和验证证据；模型的
自由文本又不稳定，不适合作为确定性审批输入。

## 决策

在进入人工审批前生成版本化 `ApprovalPackage`。稳定主题包含任务合同哈希和人工可读摘要、
结构化 Agent 结果、变更快照、测试部署回执和验证报告。主题使用规范 JSON 计算 SHA-256；模型
最终自由文本和生成时间不参与哈希。验证必须成功并至少提供一个 Evidence 引用。

审批决定必须携带完全相同的 `subject_hash`。在最终 Git 发布前再次计算工作区变更摘要；代码变化
时旧审批失效并回滚测试部署。

## 结果

审批可以明确追溯到合同、候选代码、测试部署和证据，且不会受模型措辞变化影响。后续控制台只需
渲染同一审批包，不应自行重建或修改审批主题。
